# Test Cases – Float Value Sorting

## Test Case ID: TC-FLOAT-001
**Title:** Verify sorting by float value (Lowest to Highest)

**Precondition:**
- Open the Application (https://tradeit.gg/) in any Browser
- User is on item listing page
- All filters are turned off

**Steps:**
1. Select sorting option: Float Value (Ascending)
2. Observe item order

 
 **Expected Result (ER):**
 
Items are sorted correctly from lowest to highest float value.

**Actual Result:**

Items appear in inconsistent/ random order.

**Status:**
Fail
